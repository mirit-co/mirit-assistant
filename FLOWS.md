# Bot Conversation Flows

## Legend

```
[/cmd]        — команда
[Button]      — inline-кнопка (нет ввода, нет API)
(text input)  — бот ждёт свободный текст от пользователя
★ API         — вызов Claude API
✦ DB          — только чтение/запись в SQLite
```

---

## /lists

```
[/lists]
    └─✦ DB: загрузить все списки
        └─ [books] [movies] [ideas] [shopping] ...
                │
                └─ выбрал список
                    └─✦ DB: загрузить items
                        ├─ [✓ item1]  [✗ item2]  [✗ item3]
                        ├─ [+ Добавить]  [← Назад]
                        │
                        ├─ нажал [+ Добавить]
                        │   └─ (text input: "Что добавить?")
                        │       └─✦ DB: INSERT item
                        │           └─ вернуться к списку
                        │
                        └─ нажал на item
                            └─ [✓ Выполнено]  [🗑 Удалить]  [← Назад]
                                ├─✦ DB: UPDATE done=1
                                └─✦ DB: DELETE item
```

**API:** ❌ никогда

## /knowledge

```
[/knowledge]
    └─ [Georgian Contacts] [Notes] [+ Новая категория]
            │
            ├─ выбрал категорию (например "Georgian Contacts")
            │   └─ [🔍 Найти]  [📋 Последние]  [+ Добавить]  [← Назад]
            │       │
            │       ├─ [🔍 Найти]
            │       │   └─ (text input: "Что ищешь?")
            │       │       └─★ API: поиск по контенту категории
            │       │           └─ результаты с кнопками [подробнее #id]
            │       │
            │       ├─ [📋 Последние]
            │       │   └─✦ DB: SELECT last 10
            │       │       └─ список с кнопками [подробнее #id]
            │       │
            │       └─ [+ Добавить]
            │           └─ (text input: "Текст заметки")
            │               └─✦ DB: INSERT note  (без API)
            │
            └─ [+ Новая категория]
                └─ (text input: "Название категории")
                    └─✦ DB: создать категорию
```

**API:** ✅ только в шаге "Найти" (поиск по смыслу)

## Правила включения API

| Ситуация | API нужен? | Почему |
|----------|-----------|--------|
| Навигация по меню | ❌ | Всё управляется кнопками |
| Добавить item в список | ❌ | Просто сохранить текст |
| Показать список / заметки | ❌ | Запрос к DB |
| Удалить / отметить done | ❌ | Запрос к DB |
| Добавить заметку | ❌ | Просто сохранить текст |
| **Поиск по базе знаний** | ✅ | Нужно понять смысл запроса |
| **Новая категория с авто-тегами** | ✅ (опционально) | Можно добавить позже |

## Как добавить новый раздел

1. Добавить кнопку в меню `/knowledge` или создать новую команду
2. Создать `handlers/myflow.py` с `ConversationHandler`
3. Описать состояния (States) и переходы
4. Зарегистрировать в `main.py`
5. Если нужен API — добавить вызов только в нужном состоянии

**Шаблон состояний:**
```python
# Без API: DB-only flow
MENU → VIEW → (text input) → DB write → VIEW

# С API: search flow  
MENU → (text input) → API call → показать результаты → MENU
```
