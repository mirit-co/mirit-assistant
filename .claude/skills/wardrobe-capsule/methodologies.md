# Methodologies & Style Archetypes

## When to recommend which capsule methodology

After Phase 2 (preferences captured), recommend a named methodology that fits
the user's profile. Don't push it — present 1–2 options and let them choose.

| User profile | Recommended methodology | Why |
|---|---|---|
| Overwhelmed, doesn't know where to start | **10×10 Challenge** (10 items, 10 days) | No commitment; learns mix-and-match by doing |
| Wants strict decluttering, embraces constraints | **Project 333** (33 items, 3 months) | Hard limit forces hard choices |
| Loves shopping but wants control | **5-Piece French** (basics core + 5 new pieces per season) | Permits novelty; constrains volume |
| Methodical, wants to derive personal style | **Curated Closet** (Anuschka Rees outfit-formula approach) | Lifestyle pie + outfit formulas |
| Travel / packing focus | **Vivienne Files 4×4** (16 pieces in two neutral cores) | Optimized for portability |
| Career / investment-focused | **Susie Faux classic capsule** (10–12 anchor pieces) | Quality-first long-term core |

### Project 333 — quick rules
- 33 items including clothing, accessories, jewelry, outerwear, shoes
- Excluded: underwear, sleepwear, in-home loungewear, workout clothes,
  wedding ring / sentimental everyday jewelry
- Box up everything else for 3 months; don't wear, don't buy
- Refresh every 3 months (4 capsules per year)

### 5-Piece French Wardrobe — quick rules
- Build a strong basics foundation (no item count limit, but quality + neutrals)
- Buy only 5 *new non-basic* pieces per season (= 10/year)
- Each new piece must mix-and-match with existing basics

### 10×10 Challenge — quick rules
- Pick 10 items: tops, bottoms, shoes for "everyday life"
- Excluded: accessories, bags, PJs, gym clothes (these flow freely)
- Wear only those 10 items for 10 days; create a new outfit each day

### Curated Closet (Anuschka Rees) — quick rules
- Photograph every outfit you wear for 2 weeks
- Build lifestyle pie chart from the photos
- Derive **outfit formulas** — repeatable templates like "A-line skirt +
  button-down + slip-on mules"
- Stock 2–3 versions of each formula slot
- Compose ratio: basics / mid-range / statement ≈ 1/3 : 1/3 : 1/3

### Vivienne Files 4×4 — quick rules
- 16 pieces in 4 quartets:
  - Core of Four in **neutral A** (typically 2 tops + 2 bottoms)
  - Core of Four in **neutral B**
  - Expansion Four — pieces that bridge the two neutrals
  - Mileage Four — accent tops to extend bottom-piece wear

## Style archetype menu

When the user struggles with the Three-Word Method in Phase 2, offer this
menu. Most people are hybrids of 2 archetypes — that's fine.

| Archetype | Vibe | Key items | Palette |
|---|---|---|---|
| **Classic** | Polished, timeless, never trendy | Trench, white shirt, dark jeans, leather loafer, blazer | Navy, white, beige, camel, black |
| **Minimalist** | Clean lines, no logos, considered shapes | Simple knits, monochrome layering, structured outerwear | Black, white, grey, single accent |
| **Romantic** | Soft, feminine, drapey | Floral dresses, soft blouses, ballet flats, midi skirts | Cream, blush, soft blues, dusty rose |
| **Edgy** | Sharp, unexpected, often dark | Leather jacket, combat boots, asymmetric cuts, ripped denim | Black, charcoal, occasional red/burgundy |
| **Bohemian** | Layered, textured, earthy | Maxi dresses, kimonos, fringe, ankle boots | Earth tones, mustard, terracotta, cream |
| **Preppy** | Clean, sporty, traditional | Polo, chinos, loafers, sweater tied over shoulders | Navy, white, red, kelly green |
| **Sporty** | Performance-influenced casual | Sneakers, joggers, technical jackets, hoodies | Black, white, grey, primary accents |
| **Dramatic** | Bold silhouettes, strong color, statement-led | Wide-leg trousers, oversized blazers, bold patterns | High-contrast, jewel tones |
| **Coastal / Quiet luxury** | Relaxed, expensive, undone | Linen, knits, beige + white, leather sandals | Cream, taupe, white, navy, soft blue |
| **Streetwear** | Urban, oversized, sneaker-focused | Hoodies, joggers, statement sneakers, caps | Black, white, neutrals + bold accents |
| **Eclectic** | Maximalist, mixed, personality-led | Whatever resonates, often vintage/thrifted mixed with new | Multi |

## Three-Word Method (Allison Bornstein)

Have the user pick **three adjectives**:
1. **Realistic** — what you actually reach for most often
2. **Aspirational** — where you want your style to grow
3. **Emotional** — how you want to feel when dressed

Examples:
- *Comfortable / Parisian / effortless*
- *Minimal / sharp / confident*
- *Sporty / refined / capable*
- *Practical / playful / grounded*
- *Classic / cool / put-together*

The combination of realistic + aspirational creates the gradient to grow
along; the emotional word is the gut-check ("does this outfit make me feel
[confident]?") for individual purchase decisions.

## Color palette construction

After picking neutrals + mains + accents, validate the result:

- **Neutrals (50–70%)**: 1–3 base neutrals. Default the choice to whatever
  already dominates the existing inventory — fighting reality is wasteful.
- **Main colors (20–30%)**: 2–3 colors that play with all chosen neutrals.
  Use a color wheel: complementary (opposite), analogous (adjacent), or
  triadic (evenly spaced) groupings all work.
- **Accents (10–20%)**: 1–3 colors used in small doses for energy.

Common neutral pairings that always work:
- Black + white + grey (high contrast, urban minimalist)
- Black + camel + white (classic, warm)
- Navy + white + beige (preppy / coastal)
- Charcoal + cream + brown (warm minimalist / quiet luxury)
- Olive + black + cream (utilitarian / earthy minimalist)

## Composition ratios (Anuschka Rees)

Across each major item category, aim for thirds:

- **Basics** (1/3) — workhorses, layering pieces, plain in cut and color
- **Mid-range** (1/3) — items with some character (interesting cut, subtle
  pattern) but still versatile
- **Statement** (1/3) — emotional anchors with bold color/pattern/cut

A wardrobe of all basics is boring; all-statement is unwearable. The thirds
ratio balances daily-wear utility with self-expression.
